# Sistema de Control de Estacionamiento Vehicular

## Descripción

Proyecto académico desarrollado para la materia de Ingeniería de Requisitos y Trazabilidad.

El sistema tiene como objetivo automatizar el control de ingreso y salida de vehículos, administrar espacios disponibles y facilitar el cálculo de pagos dentro de un estacionamiento vehicular.

---

## Objetivo General

Desarrollar un sistema web que permita gestionar eficientemente el registro de vehículos, el control de espacios y la facturación del servicio de estacionamiento.

---

## Funcionalidades Principales

- Registro de ingreso de vehículos.
- Registro de salida de vehículos.
- Control de espacios disponibles.
- Cálculo automático de pagos.
- Generación de reportes.
- Gestión de usuarios.

---

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- MySQL
- PlantUML

---

## Arquitectura

El sistema utiliza una arquitectura de tres capas:

1. Presentación
2. Lógica de Negocio
3. Datos
